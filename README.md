# Ghostboard · 幽灵灵感板

把灵光一闪变成完成的作品。一个面向视频、代码和写作者的本地优先创作看板。

## 启动

需要 Node.js 18 或更新版本，无需安装依赖。

```sh
npm start
```

浏览器打开 <http://127.0.0.1:4173>。停止服务按 Ctrl+C。可通过 `PORT` 环境变量调整端口。

## 功能

- 三阶段工作流：灵光一闪 → 正在酝酿 → 已经唤醒。
- 新增、编辑、删除创意，按视频、代码、写作分类。
- 搜索标题和笔记，统计进度，轮换本地创作提示。
- LocalStorage 本地保存，JSON 备份、校验与恢复，Markdown 导出。
- 手机及桌面布局，键盘操作、语义化标签及原生对话框。

第一次打开会显示四条示例。示例仅供演示，不代表真实完成的个人作品。点击卡片的“编辑”可修改状态或删除。

## 数据与隐私

没有账号、分析脚本、外部字体、AI API 或云同步。数据只保存在当前浏览器的当前站点，服务器不接收创作内容。更换浏览器、端口或清理网站数据可能导致看不到原记录；请定期“备份 JSON”。无痕模式的数据可能在退出后丢失。备份可能包含个人笔记，请自行保管。导入会替换当前记录并要求确认；删除不可撤销。

## 检查

```sh
npm test
```

Node 原生测试覆盖备份校验、重复 ID 拒绝、搜索与分类、Markdown 导出。

## 项目结构

`index.html` 为页面；`style.css` 为响应式视觉；`app.js` 处理交互和存储；`model.mjs` 提供可测试的数据校验及导出；`server.mjs` 是只允许应用文件的本地静态服务器。
